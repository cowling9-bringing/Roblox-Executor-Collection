## FAQ

### What is XCutors and is it safe?

XCutors is an open-source launcher that bundles several popular, third-party Roblox script executors. We do not develop the core executors. Always scan files yourself and use at your own risk.

### Why do I need to disable my anticomponent?

Script executors interact with game processes, which some security software may flag as suspicious. This is a common false positive. You can whitelist the folder for a more permanent solution.

### Is using this bannable in Roblox?

Using any third-party executor or script violates Roblox's Terms of Service. There is always a risk of account suspension. Use on alt accounts.

### Do I need to buy licenses for the executors?

This package is a launcher; it does not provide licenses. Some included executors (like Synapse Z) are paid software. You must own a valid license to use them. Others may be free or have free alternatives.

### The universal loader isn't injecting. What do I do?

Ensure you are running as Administrator. Check that your executor is supported and up-to-date. Check the logs tab for error details and visit the Issues page.

### Which Windows versions are supported?

XCutors is designed for Windows 10 and Windows 11 (64-bit). Older Windows versions are not officially supported.

### Can I add my own executor to the launcher?

Yes! The launcher is configurable. Place the executor's files in the 'Executors' subfolder and follow the format in the 'config.json' file to add it to the list.
